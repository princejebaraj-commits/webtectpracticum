    Positioning in practice

    Five CSS positioning techniques, each shown live and used in this dashboard: the map badge, camera tags, sticky header and table heading, back-to-top button and hotline tab.

    Static Default · Predictable

    The natural, normal-flow position. Offsets such as top have no effect.

    Block A
    Static
    Block C
    .pos-static { position: static; }

    Relative Offset · Anchored

    Shifted from its normal spot, which stays reserved. It also anchors absolute children.

    Block A
    Relative
    Block C
    .pos-relative { position: relative;
  top: 8px; left: 28px; }

    Absolute Precise · Detached

    Removed from the flow and placed exactly inside its nearest positioned parent.

    Block A
    Block C
    Absolute
    .demo-anchor { position: relative; }
.pos-absolute { position: absolute;
  top: 8px; right: 8px; }

    Fixed Persistent · Viewport-locked

    Pinned to the browser window. Scroll the page: the ↑ button and the Hotline tab never move.

    Fixed items on this page: Back to top and Hotline
    .totop, .hotline { position: fixed;
  bottom: 20px; }

    Sticky Hybrid · Scroll-aware

    Scrolls normally until it reaches its threshold, then sticks. Scroll inside the box to see the heading hold.
